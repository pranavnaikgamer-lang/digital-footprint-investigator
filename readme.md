# Digital Footprint Investigator 🔍

A Python-based web application that analyses publicly accessible website information using Streamlit.

## Features

- URL validation
- Website information and metadata extraction
- Internal and external link discovery
- Technology detection:
  - WordPress
  - React
  - Bootstrap
  - jQuery
  - Vue.js
  - Angular
- HTTPS and mixed-content analysis
- Security header inspection
- Cookie security configuration analysis

## Technologies Used

- Python
- Streamlit
- Requests
- BeautifulSoup
- urllib

## Installation

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install dependencies:

   `pip install -r requirements.txt`

4. Run the application:

   `streamlit run app.py`

## Project Status

Working prototype. Further improvements, including an enhanced security assessment and final report dashboard, are planned.

## Disclaimer

This tool performs basic passive analysis of publicly accessible website information. It is not a vulnerability scanner or a substitute for a professional security audit.
